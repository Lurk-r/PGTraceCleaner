# Pixel Gun Trace Cleaner - PGTC
(aka PG BanTraceCleaner)

PGTC is a simple script made to reduce ban chances when creating or playing on new PG accounts by cleaning local traces (i.e account/ban traces, useless data, logs) left by Pixel Gun 3D/PG3D.

### [DOWNLOAD](https://github.com/Lurk-r/PG-Trace-Cleaner/releases/latest/download/PGTraceCleaner.exe)

---
## Features

- Scan & wipe PG's temp files & logs.
- Clear registry values contain account/ban traces.
- Find and list your PG's account IDs found under PG's local data.
- Your PG settings won't reset when switching/creating new account.
- Fix some local/user-side bugs (ie. stuck on loading screen)
- Lightweight & portable.
